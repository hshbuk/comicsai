# שרת קריאה מקומי (Tachiyomi / Mihon / Aniyomi / OPDS)

השרת המובנה ב-`app/reader_api.py` מאפשר לקרוא את כל הפרויקטים שיצרתם ישירות מאפליקציות קריאת קומיקס ומנגה ברשת הביתית, ללא צורך בהעברת קבצים ידנית או בחשיפה לאינטרנט החיצוני.

## הכנת השרת
1. הפעילו את השרת עם האזנה לרשת הביתית (`--host 0.0.0.0 --port 8000` או אפשרות `[1]` ב-`ComicsAI.bat`).
2. ודאו שהמחשב והטלפון מחוברים לאותה רשת Wi-Fi ביתית.
3. העתיקו את כתובת ה-LAN שמוצגת ב-`ComicsAI.bat` (למשל `http://192.168.1.25:8000`).

---

## חיבור ל-Tachiyomi / Mihon / Aniyomi (באמצעות LANraragi)

השרת מממש את פרוטוקול ה-API של **LANraragi**, שלו יש הרחבה רשמית מובנית:

1. התקינו באפליקציה את ההרחבה **LANraragi**.
2. פתחו את הגדרות ההרחבה והזינו בכתובת השרת את הכתובת המקומית:
   ```text
   http://<LAN_IP>:8000
   ```
3. השאירו את שדה ה-API Key / סיסמה ריק.
4. רעננו את המקור — כל הפרויקטים בתיקיית `outputs/` יופיעו עם כריכה, תקציר, סגנון וכל הדפים לפי הסדר.

---

## חיבור לקוראי OPDS

עבור אפליקציות התומכות בתקן **OPDS 1.2** (כגון KOReader, Panels, Moon+ Reader):

1. הוסיפו קטלוג OPDS חדש בכתובת:
   ```text
   http://<LAN_IP>:8000/opds
   ```
2. כל פרויקט מופיע עם תמונת שער וקישור ישיר להורדת קובץ `.cbz` הכולל `ComicInfo.xml`.
